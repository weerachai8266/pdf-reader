# PDF Reader

โปรแกรมอ่าน PDF บน Windows ที่เบา เปิดเร็ว ไม่มีโฆษณาหรือบังคับล็อกอิน รองรับภาษาไทย และมีเครื่องมือไฮไลต์ โน้ต เซ็นเอกสาร กับจัดการหน้าให้ใช้ฟรี

สร้างด้วย Electron + [pdf.js](https://github.com/mozilla/pdf.js) (ใช้แสดงผล) + [pdf-lib](https://github.com/Hopding/pdf-lib) (ใช้บันทึกไฟล์)

## เริ่มใช้งาน

```bash
npm install
npm start            # เปิดโปรแกรม
npm start -- ไฟล์.pdf # เปิดพร้อมไฟล์
npm run dev          # เปิดพร้อม DevTools
npm test             # smoke test แบบ end-to-end
npm run dist         # สร้างไฟล์ติดตั้ง Windows → dist/
npm run icons        # สร้างไอคอนใหม่จาก build/logo.svg
```

การติดตั้งหลายเครื่องและระบบอัปเดต ดูได้ที่ [DEPLOY.md](DEPLOY.md)

ฟอนต์ที่ใช้คือฟอนต์ของ Windows เอง (Segoe UI สำหรับอังกฤษ และ Leelawadee UI สำหรับไทย) จึงไม่ต้องโหลดฟอนต์เพิ่ม

ไอคอนบนแถบเครื่องมือเป็นไอคอนเส้นจาก [Lucide](https://lucide.dev) (ISC) รวมไว้ในไฟล์เดียว `src/img/icons.svg` ถ้าต้องการไอคอนเพิ่ม ให้เพิ่มชื่อใน `tools/make-icon-sprite.js` แล้วรัน `node tools/make-icon-sprite.js`

## ฟีเจอร์

| ด้าน | รายละเอียด |
|---|---|
| ความเร็ว | เรนเดอร์เฉพาะหน้าที่อยู่ใกล้หน้าจอ หน้าที่เลื่อนออกไปไกลจะคืนหน่วยความจำ ส่วน pdf-lib จะโหลดเฉพาะตอนบันทึก |
| แท็บ | เปิดหลายไฟล์พร้อมกันได้ แต่ละไฟล์อยู่ในแท็บของตัวเองด้านบน (File → Open, ลากไฟล์มาวาง หรือดับเบิลคลิกไฟล์ PDF ขณะโปรแกรมเปิดอยู่) เปิดไฟล์ที่เปิดอยู่แล้วจะสลับไปแท็บนั้น แท็บที่ยังไม่บันทึกมีจุดสีฟ้า `Ctrl+T` แท็บใหม่ · `Ctrl+W` ปิดแท็บ (ถามก่อนถ้ายังไม่บันทึก) · `Ctrl+Tab` / `Ctrl+Shift+Tab` สลับแท็บ · คลิกปุ่มกลางเมาส์ที่แท็บเพื่อปิด |
| ภาษาไทย | ค้นหาได้แม้ไฟล์ที่ข้อความไทยเพี้ยน (ํา→ำ, อักขระ PUA, zero-width, วรรณยุกต์หาย) โดยค้นแบบตรงตัวก่อน ถ้าไม่เจอจะค้นแบบไม่สนวรรณยุกต์ และทำความสะอาดข้อความตอนคัดลอก |
| ไฮไลต์ | ลากเลือกข้อความแล้วกดสี (มี 4 สี) หรือเปิดโหมดไฮไลต์ด้วยปุ่ม H |
| ขีดเส้นใต้ / ขีดฆ่า | ปุ่ม Underline (คีย์ U) และ Strikethrough (คีย์ K) ลากเลือกข้อความแล้วปล่อย มีสีหมึก 4 สี (แดง น้ำเงิน เขียว ดำ) |
| รูปทรง | ปุ่ม Shapes เลือกสี่เหลี่ยม วงรี เส้นตรง หรือลูกศร แล้วลากบนหน้า ใช้เครื่องมือ Select ลากเพื่อย้าย คลิกสีเพื่อเปลี่ยนสีของรายการที่เลือก กด Delete เพื่อลบ |
| กล่องข้อความ | ปุ่ม Text Box คลิกบนหน้าแล้วพิมพ์ (หลายบรรทัดได้) เป็นกล่องพื้นขาวขอบสี ลากย้ายได้ ดับเบิลคลิกเพื่อแก้ข้อความ ข้อความที่บันทึกเป็นข้อความจริง ค้นหาและคัดลอกได้ |
| ตราประทับ | ปุ่ม Stamp มีตราสำเร็จรูป (อนุมัติ ไม่อนุมัติ สำเนาถูกต้อง ได้รับแล้ว ตรวจแล้ว ด่วน ด่วนที่สุด ลับ ลับมาก ยกเลิก ร่าง APPROVED) เลือกสี แดง/น้ำเงิน/เขียว และใส่วันที่วันนี้ (พ.ศ.) ได้ พิมพ์ข้อความเองได้ หรือใช้รูปตรายางของหน่วยงาน (Use Image… แนะนำ PNG พื้นใส โปรแกรมจำไว้ 6 รูป) วางแล้วลากย้ายและปรับขนาดได้ |
| โน้ต | กด N แล้วคลิกบนหน้า ไฟล์ที่บันทึกจะเก็บเป็น comment จริง (`/Text` annotation) ที่ Acrobat ก็เปิดอ่านได้ |
| เซ็น | วาดลายเซ็นหรือใช้รูปภาพ จากนั้นวาง ลากย้าย และปรับขนาดได้ โปรแกรมจะจำลายเซ็นที่ใช้ล่าสุดไว้ 6 อัน |
| จัดการหน้า | ลากภาพย่อยเพื่อเรียงหน้า หมุน ลบ และรวมไฟล์ PDF หลายไฟล์ · Document → Insert Pages → From File แทรกหน้าจากไฟล์อื่น (PDF, Word, Excel, รูปภาพ) ก่อนหรือหลังหน้าที่เลือก · Blank Page แทรกหน้าว่างขนาดเดียวกับหน้าข้างเคียง |
| Flatten | Document → Flatten Form & Comments ฝังช่องฟอร์ม (พร้อมค่าที่กรอก) ไฮไลต์ ตราประทับ และคอมเมนต์ลงในเนื้อหน้าตามที่เห็น แล้วกด Save ไฟล์จะแก้ไขไม่ได้อีกในทุกโปรแกรม ลิงก์ยังคลิกได้ |
| กรอกฟอร์ม | กรอกช่องข้อความ checkbox radio และ dropdown ได้ กด Tab เพื่อไปช่องถัดไป ถ้ากรอกฟอร์มอย่างเดียวจะบันทึกแบบ incremental โดยไม่แตะส่วนอื่นของไฟล์ ถ้ากรอกภาษาไทยจะฝังฟอนต์ Tahoma (เฉพาะตัวอักษรที่ใช้ ประมาณ 10 KB) ให้ช่องนั้นแสดงผลถูกในทุกโปรแกรมและตอนพิมพ์ |
| พิมพ์ | `Ctrl+P` หรือ File → Print… เปิดหน้าต่าง Print ของโปรแกรมเอง (แบบ Acrobat) เลือกเครื่องพิมพ์ (ปุ่ม Properties เปิดการตั้งค่าของไดรเวอร์) จำนวนสำเนา เรียงชุด พิมพ์ขาวดำ ช่วงหน้า (ทุกหน้า / หน้าปัจจุบัน / 1-3, 5) เฉพาะหน้าคี่หรือคู่ พิมพ์ย้อนจากหน้าสุดท้าย ขนาด (Fit, Actual size, Shrink oversized pages, Custom scale) กระดาษ A4/A3/A5/Letter/Legal แนวกระดาษ (Auto/Portrait/Landscape) และพิมพ์สองหน้า พร้อมภาพตัวอย่างทีละแผ่น แล้วส่งงานตรงไปที่เครื่องพิมพ์ สิ่งที่พิมพ์ตรงกับไฟล์ที่บันทึก (รวมฟอร์ม ไฮไลต์ และลายเซ็น) ที่ 300 dpi โปรแกรมจำเครื่องพิมพ์และการตั้งค่าล่าสุดไว้ |
| OCR | ปุ่ม OCR หรือ Tools → Recognize Text อ่านข้อความไทยและอังกฤษจากภาพสแกน แล้วฝังเป็นข้อความที่มองไม่เห็นทับไว้ (วิธีเดียวกับ Acrobat) หน้าตาเอกสารเหมือนเดิม แต่ค้นหา เลือก และคัดลอกได้ ทำงานออฟไลน์ทั้งหมด ประมาณ 1–3 วินาทีต่อหน้า ข้ามหน้าที่มีข้อความอยู่แล้วได้ และจะแจ้งเตือนเมื่อเปิดไฟล์ที่เป็นภาพสแกน |
| คัดลอกข้อความจากพื้นที่ | ปุ่ม Copy Text from Area (Tools → Copy Text from Area) ลากกรอบคลุมข้อความ ข้อความในกรอบจะถูกคัดลอกตามลำดับบรรทัด ถ้าเป็นหน้าสแกนที่ยังไม่ได้ทำ OCR จะอ่านด้วย OCR เฉพาะส่วนนั้นให้ (ควรตรวจทาน) |
| แยก/ดึงหน้า | Document → Extract Pages ดึงหน้าที่เลือก (เช่น `1-3, 5, 8-`) เป็นไฟล์ใหม่ หรือแยกหน้าละไฟล์ และเลือกลบหน้านั้นออกจากเอกสารได้ ส่วน Split Document แยกทุก N หน้า หรือแยกตามช่วงหน้า (`1-3; 4-10; 11-`) ลงโฟลเดอร์ที่เลือก ไฟล์ที่มีชื่อซ้ำจะไม่ถูกทับ |
| เลขหน้า / Header & Footer | ใส่ข้อความได้ 6 ตำแหน่ง (หัว/ท้ายกระดาษ ซ้าย กลาง ขวา) รองรับภาษาไทย ใช้ `{page}` `{total}` `{date}` `{file}` แทนค่าได้ ตั้งขนาดตัวอักษร ระยะจากขอบ สี และเลขเริ่มต้นได้ หน้าที่หมุนอยู่ก็ยังวางตำแหน่งตามที่เห็นบนจอ |
| ลายน้ำ | ข้อความกลางหน้า แนวเฉียงหรือแนวนอน ปรับขนาดอัตโนมัติให้พอดีหน้า และตั้งสีกับความโปร่งใสได้ |
| Redact | เครื่องมือ ⬛ Redact ใช้ลากกรอบคลุมส่วนที่ต้องการลบ แล้วกด Apply Redactions เนื้อหาใต้กรอบจะถูกลบออกจากไฟล์จริง ไม่ใช่แค่ทับสีดำ (หน้านั้นถูกแปลงเป็นภาพ และข้อความ ลิงก์ ความคิดเห็น ช่องฟอร์ม ภาพย่อ และ object เดิมถูกลบออกหมด) จากนั้นทำ OCR ให้ค้นหาข้อความส่วนที่เหลือได้ ถ้ากด Save ก่อน Apply โปรแกรมจะเตือน |
| ลดขนาดไฟล์ | Document → Reduce File Size ย่อรูปที่ละเอียดเกินจำเป็น (เลือกได้ 200/150/100 dpi) ด้วย JPEG แล้วจัดระเบียบไฟล์ด้วย qpdf บันทึกเป็นไฟล์ใหม่ `_reduced.pdf` และบอกว่าลดไปกี่ % |
| ป้องกันไฟล์ | Document → Protect with Password ตั้งรหัสผ่านเปิดไฟล์ และ/หรือจำกัดสิทธิ์ (การพิมพ์ การแก้ไข การคัดลอก) เข้ารหัส AES-256 ส่วน Remove Security ใช้ปลดรหัส โดยต้องใช้รหัสผ่านเปลี่ยนสิทธิ์ ไม่ใช่รหัสผ่านเปิดไฟล์ |
| สร้าง PDF | File → Create PDF from File… (หรือลากไฟล์มาวาง) แปลง Word, Excel, PowerPoint, ODF, RTF, TXT, HTML และรูปภาพ (JPG, PNG, GIF, BMP, WebP, TIFF) เป็น PDF เลือกหลายไฟล์ได้ ทุกไฟล์จะรวมเป็นเอกสารเดียว ส่วน Combine Files ก็รับไฟล์เหล่านี้ได้เช่นกัน แปลงด้วย LibreOffice ที่ติดมากับโปรแกรม ทำงานออฟไลน์ ครั้งแรกใช้เวลาประมาณ 5 วินาที ครั้งต่อไปประมาณ 1–2 วินาทีต่อไฟล์ ข้อความภาษาไทยในไฟล์ที่แปลงแล้วค้นหาและคัดลอกได้ถูกต้อง (โปรแกรมซ่อมตาราง ToUnicode ที่ LibreOffice เขียนไม่ครบ) |
| แปลง PDF ออก | File → Export To → Word (.docx) ดึงข้อความ หัวข้อ ตัวหนา การจัดกึ่งกลาง และการขึ้นหน้าใหม่ · Image (PNG/JPEG 96–300 dpi เลือกช่วงหน้าได้) · Plain Text (.txt, UTF-8 เปิดใน Notepad แล้วภาษาไทยไม่เพี้ยน) |
| ลายเซ็นดิจิทัล | ปุ่มปากกาบนแถบเครื่องมือ หรือ Tools → Sign with Certificate ลากกรอบตำแหน่งลายเซ็น (หรือเซ็นแบบไม่แสดงกรอบ) แล้วเลือก Digital ID ใช้ไฟล์ .pfx/.p12 จากผู้ให้บริการออกใบรับรอง (Import…) หรือสร้าง Digital ID ของตัวเองในโปรแกรม (New Digital ID…, RSA 2048 บิต อายุ 5 ปี) ลายเซ็นเป็นมาตรฐาน PKCS#7 แบบเดียวกับ Acrobat และต่อท้ายไฟล์แบบ incremental จึงเซ็นต่อกันได้หลายคนโดยลายเซ็นก่อนหน้ายังถูกต้อง |
| ตรวจลายเซ็น | เปิดไฟล์ที่มีลายเซ็นดิจิทัลแล้วจะมีแถบสถานะเหนือหน้าเอกสาร (เขียว = ถูกต้อง, เหลือง = ยังยืนยันตัวตนผู้เซ็นไม่ได้, แดง = เอกสารถูกแก้ไขหลังเซ็น) โปรแกรมเทียบฉบับที่ถูกเซ็นกับฉบับปัจจุบัน จึงแยกได้ว่าสิ่งที่ต่อท้ายมาหลังเซ็นเป็นแค่ลายเซ็นถัดไป (ยังถูกต้อง) การกรอกฟอร์มหรือเพิ่มความเห็น (ถูกต้อง แต่แจ้งว่ามีการเปลี่ยนแปลง) หรือการแก้เนื้อหาหน้า (แดง) และแผง Signatures ที่บอกผู้เซ็น เวลา เหตุผล ผู้ออกใบรับรอง และปุ่ม Trust Certificate สำหรับใบรับรองของคนในองค์กร ใบรับรองที่ออกโดย CA ในรายการมาตรฐาน (Mozilla) จะเชื่อถือได้ทันที ถ้าจะบันทึกการแก้ไขที่ทำให้ลายเซ็นเสีย โปรแกรมจะเตือนก่อน |
| เปรียบเทียบไฟล์ | Tools → Compare Files เลือกอีกไฟล์ แล้วระบุว่าเป็นฉบับเก่าหรือใหม่ แผง Compare จะแสดงจุดที่เพิ่ม ลบ และแก้ไข พร้อมเลขหน้า (คลิกเพื่อไปที่หน้านั้น) และไฮไลต์สีเขียวบนข้อความที่ต่างในเอกสารที่เปิดอยู่ ตัดคำภาษาไทยด้วยตัวตัดคำของ Chromium |
| แก้ข้อความ | ปุ่มดินสอบนแถบเครื่องมือ (Edit Text & Images) แล้วคลิกบรรทัดที่ต้องการ จะมีช่องแก้พร้อมข้อความเดิม ขนาด สี และฟอนต์เดิม (ตัวเลือกแรก "Original" คือฟอนต์ที่ฝังอยู่ในไฟล์ ข้อความใหม่จึงเป็นฟอนต์และขนาดเดียวกับต้นฉบับ โดยไม่ฝังฟอนต์เพิ่ม ถ้าพิมพ์ตัวอักษรที่ไม่เคยมีในเอกสาร ซึ่งฟอนต์ที่ฝังมาไม่มี โปรแกรมจะใช้ฟอนต์ชื่อเดียวกันที่ติดตั้งในเครื่อง รวมฟอนต์ที่ติดตั้งเฉพาะผู้ใช้ และถ้าไม่มีจึงใช้ฟอนต์ใกล้เคียง ส่วนตัวเลือกอื่นคือ Tahoma, TH Sarabun New, Arial, Times New Roman ปรับตัวหนาได้) กด Enter เพื่อยืนยัน ตัวอักษรเดิมถูกลบออกจากไฟล์จริง ไม่ใช่เอากล่องขาวไปปิด ข้อความอื่นในบรรทัดและหน้าอยู่ตำแหน่งเดิมทุกตัว |
| เพิ่มข้อความ | ปุ่ม T (Add Text) คลิกตรงไหนก็ได้แล้วพิมพ์ ข้อความเป็นข้อความจริงในหน้า ค้นหาและคัดลอกได้ |
| แก้รูป | ในโหมด Edit รูปบนหน้าจะมีกรอบ ลากเพื่อย้าย ลากมุมเพื่อย่อ/ขยาย กด Delete เพื่อลบ หรือกดปุ่ม Replace เพื่อเปลี่ยนเป็นรูปอื่น ส่วนปุ่ม Add Image ใช้วางรูปใหม่ |
| ย้อนกลับ | Ctrl+Z (Edit → Undo Edit) ย้อนการแก้ข้อความและรูปได้ 20 ขั้น |
| เมนู | แถบเมนู File / Edit / View / Tools / Document / Help และปุ่มทั้งหมดเป็นภาษาอังกฤษ ส่วนข้อความแจ้งเตือนเป็นภาษาไทย |
| ลิงก์ | ลิงก์ในเอกสารคลิกได้ ลิงก์ภายในจะพาไปหน้าที่ถูกต้องแม้เรียงหน้าใหม่แล้ว ลิงก์เว็บจะเปิดในเบราว์เซอร์ |
| รหัสผ่าน | เปิดไฟล์ที่มีรหัสผ่านได้ และเคารพสิทธิ์ที่เจ้าของไฟล์ตั้งไว้ (เช่น ห้ามพิมพ์) |

## คีย์ลัด

`Ctrl+O` เปิด · `Ctrl+S` บันทึก · `Ctrl+Shift+S` บันทึกเป็น · `Ctrl+P` พิมพ์ · `Ctrl+F` ค้นหา · `Enter`/`Shift+Enter` ผลถัดไป/ก่อนหน้า · `Ctrl+ล้อเมาส์` หรือ `Ctrl+=`/`Ctrl+-` ซูม · `Ctrl+0` พอดีความกว้าง · `←`/`→` เปลี่ยนหน้า · `V` เลือก · `H` ไฮไลต์ · `U` ขีดเส้นใต้ · `K` ขีดฆ่า · `N` โน้ต · `Delete` ลบรายการที่เลือก · `Ctrl+Z` ย้อนการแก้ข้อความ/รูป · `Esc` ยกเลิกเครื่องมือ

## ข้อจำกัดที่รู้อยู่แล้ว

- ไฮไลต์ ขีดเส้นใต้ ขีดฆ่า รูปทรง กล่องข้อความ ตราประทับ และลายเซ็นจะถูกฝังลงในเนื้อหน้า (flatten) ตอนบันทึก จึงแสดงผลเหมือนกันทุกโปรแกรม แต่หลังบันทึกแล้วโปรแกรมใดก็แก้หรือลบไม่ได้
- รูปทรงย้ายได้ แต่ยังปรับขนาดหลังวาดไม่ได้ (ลบแล้ววาดใหม่) ความหนาเส้นคงที่ 2 pt
- Flatten: คอมเมนต์ที่ไม่มีหน้าตาเก็บไว้ในไฟล์ (เช่น โน้ตจากบางโปรแกรม) จะยังเป็นคอมเมนต์อยู่ และ Flatten ทำให้ลายเซ็นดิจิทัลเดิมใช้ไม่ได้ (โปรแกรมเตือนก่อน)
- ไฟล์ที่มีรหัสผ่าน: บันทึกการกรอกฟอร์มได้ทันที ส่วนการจัดการหน้า ไฮไลต์ เซ็น และเครื่องมือใน Document ต้องใช้ Remove Security ก่อน ถ้ากรอกภาษาไทยลงไฟล์ที่ยังมีรหัสผ่าน หน้าตาของช่องในโปรแกรมอื่นอาจเพี้ยน (โปรแกรมจะแจ้งเตือนตอนบันทึก)
- ฟอร์มที่มี JavaScript (เช่น ช่องที่คำนวณยอดรวมอัตโนมัติ) กรอกได้ แต่สคริปต์ในฟอร์มจะไม่ทำงาน
- ฟอร์ม XFA (ฟอร์มรุ่นเก่าที่ทำด้วย Adobe LiveCycle) ยังไม่รองรับ
- Header/footer และลายน้ำภาษาไทยวาดด้วย Tahoma โดยไม่มีการจัดตำแหน่งสระซ้อนแบบเต็มรูปแบบ คำที่มีสระบนและวรรณยุกต์ซ้อนกัน (เช่น ที่ นี่) อาจดูชิดกันเล็กน้อย
- Header/footer และลายน้ำฝังลงในหน้าทันที ยังลบออกทีหลังแบบ Acrobat ไม่ได้ ถ้าใส่ผิดให้ปิดไฟล์โดยไม่บันทึก
- Redact จะแปลงหน้าที่มีกรอบเป็นภาพ (300 dpi) จึงทำให้ขนาดไฟล์ใหญ่ขึ้นและข้อความหน้านั้นเป็นข้อความจาก OCR แทน และยังไม่ลบข้อมูลระดับเอกสาร เช่น metadata หรือ bookmark ที่อาจมีข้อความลับ
- ลดขนาดไฟล์: ย่อเฉพาะรูป JPEG และรูป RGB/ขาวดำปกติ รูป CMYK และรูปพิเศษอื่นจะคงไว้เหมือนเดิม
- Export to Word ได้เฉพาะข้อความและรูปแบบพื้นฐาน ตารางจะกลายเป็นข้อความทีละบรรทัด และยังไม่ได้นำรูปภาพไปด้วย ไฟล์สแกนต้องทำ OCR ก่อน ยังไม่มี Export to Excel/PowerPoint เพราะตัวนำเข้า PDF ของ LibreOffice สลับลำดับสระภาษาไทย
- การแปลง Office เป็น PDF ใช้ฟอนต์ที่มีในเครื่อง สำหรับ TH Sarabun New / TH SarabunPSK / TH SarabunIT๙ ที่ Windows ไม่ได้ติดมาให้ โปรแกรมมีฟอนต์ Laksaman ติดมาด้วย (รูปตัวอักษรและความกว้างเหมือน TH Sarabun New ทุกตัว เผยแพร่โดย TLWG แบบ GPL) จึงตัดบรรทัดตรงกับต้นฉบับ (เครื่องที่ติดตั้งฟอนต์จริงไว้แล้วจะใช้ฟอนต์จริง) ส่วนฟอนต์อื่นที่เครื่องไม่มีจะใช้ฟอนต์ใกล้เคียงแทน
- การพิมพ์ใช้วิธีแปลงหน้าเป็นภาพ 300 dpi ตัวอักษรคมชัดพอสำหรับงานเอกสารทั่วไป แต่ไม่ได้ส่งเป็น vector เหมือน Acrobat และยังไม่พิมพ์ไอคอนโน้ต
- OCR: ความแม่นยำขึ้นกับคุณภาพสแกน (แนะนำ 300 dpi) ลายมือและตัวอักษรตกแต่งจะอ่านได้ไม่ดี และยังไม่ได้ปรับภาพสแกนที่เอียงให้ตรงก่อนอ่าน
- ฟอนต์ที่ฝังในไฟล์ส่วนใหญ่มีเฉพาะตัวอักษรที่เอกสารใช้ ถ้าบรรทัดที่แก้มีตัวอักษรใหม่แม้ตัวเดียว ทั้งบรรทัดจะใช้ฟอนต์จากเครื่องแทน (โปรแกรมแจ้งชื่อฟอนต์ที่ใช้) และถ้ากดตัวหนาเปลี่ยนจากเดิม ก็จะใช้ฟอนต์จากเครื่องเช่นกัน
- แก้ข้อความทีละบรรทัด ยังไม่จัดย่อหน้าใหม่ให้อัตโนมัติแบบ Acrobat (ถ้าข้อความใหม่ยาวกว่าเดิม จะยื่นออกไปทางขวา) ข้อความภาษาไทยที่พิมพ์ใหม่ใช้ฟอนต์จากเครื่องโดยไม่จัดตำแหน่งสระซ้อนแบบเต็มรูปแบบ
- แก้ไม่ได้: ข้อความ/รูปที่อยู่ในวัตถุซ้อน (form XObject) ฟอนต์ Type3 และฟอนต์ CID ที่ไม่ใช่ Identity-H (โปรแกรมจะแจ้งและแนะนำให้ใช้ Add Text แทน) ไฟล์สแกนเป็นภาพทั้งหน้า ให้ใช้ OCR ก่อน หรือใช้ Redact + Add Text
- ลายเซ็นดิจิทัล: ยังเซ็นด้วยบัตร smart card / USB token หรือใบรับรองใน Windows Certificate Store ไม่ได้ (ใช้ไฟล์ .pfx/.p12 เท่านั้น) และเซ็นได้เฉพาะกุญแจแบบ RSA (ตรวจลายเซ็นได้ทั้ง RSA และ EC) เวลาที่เซ็นมาจากนาฬิกาของเครื่อง ยังไม่ได้ขอตราประทับเวลา (timestamp) จาก TSA และยังไม่ตรวจการเพิกถอนใบรับรอง (CRL/OCSP)
- ถ้าลายเซ็นถัดไปเซ็นแบบมองเห็นได้ด้วยเวอร์ชัน 0.8.0–0.9.1 ลายเซ็นก่อนหน้าจะขึ้นว่าเนื้อหาถูกแก้ไข เพราะเวอร์ชันเก่าแตะเนื้อหาหน้าตอนวางกรอบลายเซ็น (แก้แล้วใน 0.9.2)
- Compare Files เปรียบเทียบเฉพาะข้อความ ยังไม่เทียบรูปภาพหรือรูปแบบตัวอักษร

## โครงสร้าง

```
main/      Electron main process, preload, updater
src/       หน้า renderer: index.html, css/, js/, img/
config/    update.json (URL เซิร์ฟเวอร์อัปเดต)
build/     โลโก้ (logo.svg) และไอคอน
tools/     สคริปต์สร้างไอคอน และ fetch-libreoffice.ps1 (เตรียมตัวแปลงไฟล์)
vendor/    LibreOffice ที่แตกไฟล์แล้ว (ไม่เก็บใน git สร้างด้วย fetch-libreoffice.ps1)
test/      smoke test (ซอร์ส) และ packaged.mjs (ทดสอบตัวที่ build แล้ว)
```

เวอร์ชันอ่านจาก `package.json` (แหล่งเดียว) และแสดงที่มุมขวาล่างของแถบสถานะ
