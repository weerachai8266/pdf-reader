# PDF Reader

โปรแกรมอ่าน PDF บน Windows ที่เบา เปิดเร็ว ไม่มีโฆษณาหรือบังคับล็อกอิน รองรับภาษาไทย และมีเครื่องมือไฮไลต์ โน้ต เซ็นเอกสาร กับจัดการหน้าให้ใช้ฟรี

สร้างด้วย Electron + [pdf.js](https://github.com/mozilla/pdf.js) (ใช้แสดงผล) + [pdf-lib](https://github.com/Hopding/pdf-lib) (ใช้บันทึกไฟล์)

## เริ่มใช้งาน

```bash
npm install
npm start            # เปิดโปรแกรม
npm start -- ไฟล์.pdf # เปิดพร้อมไฟล์
npm run dev          # เปิดพร้อม DevTools
npm test             # smoke test แบบ end-to-end
npm run dist         # สร้างไฟล์ติดตั้ง Windows → dist/
npm run icons        # สร้างไอคอนใหม่จาก build/logo.svg
```

การติดตั้งหลายเครื่องและระบบอัปเดต ดูได้ที่ [DEPLOY.md](DEPLOY.md)

ฟอนต์ที่ใช้คือฟอนต์ของ Windows เอง (Segoe UI สำหรับอังกฤษ และ Leelawadee UI สำหรับไทย) จึงไม่ต้องโหลดฟอนต์เพิ่ม

## ฟีเจอร์

| ด้าน | รายละเอียด |
|---|---|
| ความเร็ว | เรนเดอร์เฉพาะหน้าที่อยู่ใกล้หน้าจอ หน้าที่เลื่อนออกไปไกลจะคืนหน่วยความจำ ส่วน pdf-lib จะโหลดเฉพาะตอนบันทึก |
| ภาษาไทย | ค้นหาได้แม้ไฟล์ที่ข้อความไทยเพี้ยน (ํา→ำ, อักขระ PUA, zero-width, วรรณยุกต์หาย) โดยค้นแบบตรงตัวก่อน ถ้าไม่เจอจะค้นแบบไม่สนวรรณยุกต์ และทำความสะอาดข้อความตอนคัดลอก |
| ไฮไลต์ | ลากเลือกข้อความแล้วกดสี (มี 4 สี) หรือเปิดโหมดไฮไลต์ด้วยปุ่ม H |
| โน้ต | กด N แล้วคลิกบนหน้า ไฟล์ที่บันทึกจะเก็บเป็น comment จริง (`/Text` annotation) ที่ Acrobat ก็เปิดอ่านได้ |
| เซ็น | วาดลายเซ็นหรือใช้รูปภาพ จากนั้นวาง ลากย้าย และปรับขนาดได้ โปรแกรมจะจำลายเซ็นที่ใช้ล่าสุดไว้ 6 อัน |
| จัดการหน้า | ลากภาพย่อยเพื่อเรียงหน้า หมุน ลบ และรวมไฟล์ PDF หลายไฟล์ |
| กรอกฟอร์ม | กรอกช่องข้อความ checkbox radio และ dropdown ได้ กด Tab เพื่อไปช่องถัดไป ถ้ากรอกฟอร์มอย่างเดียวจะบันทึกแบบ incremental โดยไม่แตะส่วนอื่นของไฟล์ ถ้ากรอกภาษาไทยจะฝังฟอนต์ Tahoma (เฉพาะตัวอักษรที่ใช้ ประมาณ 10 KB) ให้ช่องนั้นแสดงผลถูกในทุกโปรแกรมและตอนพิมพ์ |
| ลิงก์ | ลิงก์ในเอกสารคลิกได้ ลิงก์ภายในจะพาไปหน้าที่ถูกต้องแม้เรียงหน้าใหม่แล้ว ลิงก์เว็บจะเปิดในเบราว์เซอร์ |
| รหัสผ่าน | เปิดไฟล์ที่มีรหัสผ่านได้ |

## คีย์ลัด

`Ctrl+O` เปิด · `Ctrl+S` บันทึก · `Ctrl+Shift+S` บันทึกเป็น · `Ctrl+F` ค้นหา · `Enter`/`Shift+Enter` ผลถัดไป/ก่อนหน้า · `Ctrl+ล้อเมาส์` หรือ `Ctrl+=`/`Ctrl+-` ซูม · `Ctrl+0` พอดีความกว้าง · `←`/`→` เปลี่ยนหน้า · `V` เลือก · `H` ไฮไลต์ · `N` โน้ต · `Delete` ลบรายการที่เลือก · `Esc` ยกเลิกเครื่องมือ

## ข้อจำกัดที่รู้อยู่แล้ว

- ไฮไลต์และลายเซ็นจะถูกฝังลงในเนื้อหน้า (flatten) จึงแสดงผลเหมือนกันทุกโปรแกรม แต่โปรแกรมอื่นจะแก้หรือลบไม่ได้
- ไฟล์ที่มีรหัสผ่าน: บันทึกการกรอกฟอร์มได้ แต่ยังจัดการหน้า ไฮไลต์ หรือเซ็นไม่ได้ ถ้ากรอกภาษาไทยลงไฟล์ประเภทนี้ ค่าที่กรอกจะถูกบันทึก แต่หน้าตาของช่องในโปรแกรมอื่นอาจเพี้ยน (โปรแกรมจะแจ้งเตือนตอนบันทึก)
- ฟอร์มที่มี JavaScript (เช่น ช่องที่คำนวณยอดรวมอัตโนมัติ) กรอกได้ แต่สคริปต์ในฟอร์มจะไม่ทำงาน
- ฟอร์ม XFA (ฟอร์มรุ่นเก่าที่ทำด้วย Adobe LiveCycle) ยังไม่รองรับ
- ถ้าลบหน้าแล้วบันทึก ขนาดไฟล์อาจยังไม่เล็กลง (pdf-lib ไม่ลบ object ที่ไม่ได้ใช้ออก)
- ยังไม่มี OCR สำหรับไฟล์สแกน และยังแก้ข้อความในเอกสารไม่ได้

## โครงสร้าง

```
main/      Electron main process, preload, updater
src/       หน้า renderer: index.html, css/, js/, img/
config/    update.json (URL เซิร์ฟเวอร์อัปเดต)
build/     โลโก้ (logo.svg) และไอคอน
tools/     สคริปต์สร้างไอคอน
test/      smoke test (ซอร์ส) และ packaged.mjs (ทดสอบตัวที่ build แล้ว)
```

เวอร์ชันอ่านจาก `package.json` (แหล่งเดียว) และแสดงที่มุมขวาล่างของแถบสถานะ
