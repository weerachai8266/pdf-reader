          Recognize Text (OCR)

          อ่านข้อความจากภาพสแกน แล้วฝังเป็นข้อความที่มองไม่เห็นทับไว้ หน้าตาเอกสารจะเหมือนเดิม แต่ค้นหาและคัดลอกข้อความได้ (ภาษาไทย + อังกฤษ)

          หน้าที่จะทำ

          Rotate Pages

          หมุนหลายหน้าพร้อมกัน เอกสารนี้มีทั้งหมด 0 หน้า

          หน้าที่จะหมุน

          Extract Pages

          ดึงหน้าที่เลือกออกเป็นไฟล์ใหม่ (รวมไฮไลต์ ลายเซ็น และค่าในฟอร์ม) เอกสารนี้มีทั้งหมด 0 หน้า

          Split Document

          แยกเอกสาร 0 หน้า เป็นหลายไฟล์ แล้วเลือกโฟลเดอร์ที่จะเก็บ

          วิธีแยก

          Header & Footer

          ใช้แทนค่าได้: {page} เลขหน้า · {total} จำนวนหน้า · {date} วันที่ · {file} ชื่อไฟล์ — ปล่อยว่างช่องที่ไม่ใช้

          Header

          Footer

          Add Watermark

          ใส่ข้อความลายน้ำกลางทุกหน้า

          Reduce File Size

          ย่อรูปภาพที่ละเอียดเกินจำเป็นและจัดระเบียบไฟล์ แล้วบันทึกเป็นไฟล์ใหม่ (ไฟล์เดิมไม่ถูกแก้)

          คุณภาพ

          Protect with Password

          เข้ารหัสแบบ AES-256 แล้วบันทึกเป็นไฟล์ — จำรหัสผ่านไว้ให้ดี ถ้าลืมจะเปิดไฟล์ไม่ได้อีก

          Apply Redactions

          หน้าที่มีกรอบจะถูกแปลงเป็นภาพ และข้อความ ลิงก์ ความคิดเห็น และช่องฟอร์มบนหน้านั้นจะถูกลบออกจากไฟล์ทั้งหมด ย้อนกลับไม่ได้หลังบันทึก

          Export to Images

          แปลงแต่ละหน้าเป็นไฟล์รูปภาพ แล้วเลือกโฟลเดอร์ที่จะเก็บ

          Sign with Certificate

          ลายเซ็นดิจิทัลยืนยันว่าใครเป็นผู้เซ็น และตรวจได้ว่าเอกสารถูกแก้ไขหลังเซ็นหรือไม่ ใช้ Digital ID (ไฟล์ .pfx/.p12) จากผู้ให้บริการออกใบรับรอง หรือสร้างขึ้นเองในโปรแกรม

          กด "Drag New Signature Box" แล้วลากกรอบบนหน้าตรงตำแหน่งที่จะแสดงลายเซ็น

          Sign with Certificate

          ยังไม่มี Digital ID — สร้างใหม่ หรือนำเข้าไฟล์ .pfx / .p12

          หลังเซ็น โปรแกรมจะถามที่บันทึกไฟล์ แล้วเปิดไฟล์ที่เซ็นแล้วขึ้นมาแทน

          New Digital ID

          สร้าง Digital ID แบบออกเอง (self-signed) RSA 2048 บิต อายุ 5 ปี เก็บไว้ในเครื่องนี้ ผู้รับเอกสารจะเห็นว่า "ยังยืนยันตัวตนผู้เซ็นไม่ได้" จนกว่าจะกด Trust Certificate ถ้าต้องการลายเซ็นที่ยอมรับทั่วไป ให้ใช้ใบรับรองจากผู้ให้บริการออกใบรับรอง (CA)

          Compare Files

          เปรียบเทียบข้อความระหว่างเอกสารที่เปิดอยู่ กับ

          ไฟล์ที่เลือกคือ

          เปรียบเทียบเฉพาะข้อความ ไฟล์สแกนต้องทำ OCR ก่อน

          ขนาดและการจัดหน้า

          Insert Pages

          เลือกตำแหน่งที่จะแทรกหน้า

          Stamp

          เลือกตราประทับ แล้วคลิกตำแหน่งบนหน้า (ลากเพื่อย้าย ลากมุมเพื่อปรับขนาด)

          ตรายางที่เคยใช้

          ยังไม่มีรูปตรายาง กด "Use Image…" เพื่อเลือกรูป (แนะนำ PNG พื้นใส)

          เซ็นเอกสาร

          วาดลายเซ็นในกรอบ แล้วกด "Place on Page" จากนั้นคลิกตำแหน่งบนหน้า (ลากเพื่อย้าย ลากมุมเพื่อปรับขนาด)

          ลายเซ็นที่เคยใช้

          ยังไม่มีลายเซ็นที่บันทึกไว้
