      ลากไฟล์ PDF มาวางที่นี่

      หรือ

      • Ctrl+O เปิดไฟล์
      • Ctrl+F ค้นหา
      • H ไฮไลต์ · N โน้ต
      • Ctrl+ล้อเมาส์ ซูม
      วางไฟล์เพื่อเปิด
      ยังไม่ได้เปิดไฟล์ กำลังทำงาน…

      Recognize Text (OCR)

      อ่านข้อความจากภาพสแกน แล้วฝังเป็นข้อความที่มองไม่เห็นทับไว้ หน้าตาเอกสารจะเหมือนเดิม แต่ค้นหาและคัดลอกข้อความได้ (ภาษาไทย + อังกฤษ)

      หน้าที่จะทำ

      Extract Pages

      ดึงหน้าที่เลือกออกเป็นไฟล์ใหม่ (รวมไฮไลต์ ลายเซ็น และค่าในฟอร์ม) เอกสารนี้มีทั้งหมด 0 หน้า

      Split Document

      แยกเอกสาร 0 หน้า เป็นหลายไฟล์ แล้วเลือกโฟลเดอร์ที่จะเก็บ

      วิธีแยก

      Header & Footer

      ใช้แทนค่าได้: {page} เลขหน้า · {total} จำนวนหน้า · {date} วันที่ · {file} ชื่อไฟล์ — ปล่อยว่างช่องที่ไม่ใช้

      Header

      Footer

      Add Watermark

      ใส่ข้อความลายน้ำกลางทุกหน้า

      Reduce File Size

      ย่อรูปภาพที่ละเอียดเกินจำเป็นและจัดระเบียบไฟล์ แล้วบันทึกเป็นไฟล์ใหม่ (ไฟล์เดิมไม่ถูกแก้)

      คุณภาพ

      Protect with Password

      เข้ารหัสแบบ AES-256 แล้วบันทึกเป็นไฟล์ — จำรหัสผ่านไว้ให้ดี ถ้าลืมจะเปิดไฟล์ไม่ได้อีก

      Apply Redactions

      หน้าที่มีกรอบจะถูกแปลงเป็นภาพ และข้อความ ลิงก์ ความคิดเห็น และช่องฟอร์มบนหน้านั้นจะถูกลบออกจากไฟล์ทั้งหมด ย้อนกลับไม่ได้หลังบันทึก

      เซ็นเอกสาร

      วาดลายเซ็นในกรอบ แล้วกด "Place on Page" จากนั้นคลิกตำแหน่งบนหน้า (ลากเพื่อย้าย ลากมุมเพื่อปรับขนาด)

      ลายเซ็นที่เคยใช้

      ยังไม่มีลายเซ็นที่บันทึกไว้
